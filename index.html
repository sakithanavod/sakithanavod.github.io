Published plugin

Independent work: designed, built and published by me on Fab.

Unreal Engine plugin · C++ · Blueprint API · Replicated

Sonic Interaction System

An interaction framework for Unreal Engine, from simple pickups up to multiplayer-safe gameplay systems. It decides what the player is focusing on, how an interaction is triggered, and keeps that state consistent across the network.

View on Fab Showcase video Getting started
Attention-driven focus
Chooses the interaction target from view direction, distance and visibility, and drives the on-screen indicators that guide the player toward it.
Trigger model
Press, release, hold, repeat-while-held and tap, plus custom triggers. Triggers can be combined on a single interaction.
Replication
Interactions are replicated, with interaction locking so two players can’t act on the same object at once.
Debug visualisation
Draws focus ranges, dot-product checks, gates and active candidates in real time, so tuning happens in the level instead of in guesswork.
Camera-agnostic
Works with first-person, third-person, top-down and fixed cameras without changes to the core logic.
Modular
Scales from a single interactable to system-level gameplay, with an API exposed to Blueprints for designers.
